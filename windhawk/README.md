# Volu - Windhawk Mod (macOS Volume HUD)

Официальный мод **Volu** для [Windhawk](https://windhawk.net/) — аутентичный индикатор громкости в стиле macOS для Windows.

## Преимущества твика перед отдельным приложением
1. **Работает поверх всех игр (включая Fortnite, CS2, Cyberpunk):**  
   Твик работает напрямую внутри процесса `explorer.exe` и создаёт окно с использованием системного Z-бэнда уведомлений Windows (`ZBID_IMMERSIVE_NOTIFICATION`). Это гарантирует отображение даже поверх эксклюзивных полноэкранных игр.
2. **Перехват и подавление стандартного флайаута Windows:**  
   При нажатии клавиш громкости твик подавляет показ стандартного окна громкости Windows, заменяя его на элегантный оверлей macOS.
3. **Умное определение активного монитора:**  
   Худ автоматически центрируется на том мониторе, на котором развёрнута активная игра или окно приложения.
4. **Встроенные оригинальные звуки:**  
   Звуки кликов деревянного щелчка macOS (`WoodClick`) и тактильного щелчка (`TactileClick`) вшиты прямо в код — никаких внешних файлов не требуется.
5. **Поддержка настроек Windhawk:**  
   Стиль звука, тайм-аут, позицию на экране и горячие клавиши можно настраивать прямо из графического интерфейса Windhawk.

## Как установить твик локально прямо сейчас (2 шага)

1. Откройте **Windhawk**.
2. В правом верхнем углу нажмите меню из трех точек `...` (или настройки) → **Параметры разработчика** (*Developer Options*) → **Создать новый мод** (*Create a new mod*).
3. В открывшемся редакторе Windhawk:
   - Замените весь шаблонный код содержимым файла [`volu-macos-volume-hud.wh.cpp`](file:///C:/Users/aleks/.gemini/antigravity/scratch/Volu/windhawk/volu-macos-volume-hud.wh.cpp).
   - Нажмите кнопку **Скомпилировать** (*Compile* или клавиши `Ctrl + B`).
4. Всё готово! Твик скомпилируется и сразу же начнёт работать в системе.

## Как добавить твик во встроенный каталог ("магазин") Windhawk

Чтобы любой пользователь мог установить Volu в один клик из раздела **Обзор** (*Explore*) в Windhawk:

1. Сделайте Fork репозитория [ramensoftware/windhawk-mods](https://github.com/ramensoftware/windhawk-mods) на GitHub.
2. Скопируйте два файла из этой папки в папку `mods/` форка:
   - `volu-macos-volume-hud.wh.cpp`
   - `volu-macos-volume-hud.png`
3. Создайте Pull Request в ветку `main` репозитория `ramensoftware/windhawk-mods`.
4. После одобрения автором Windhawk твик появится во встроенном магазине приложения!
