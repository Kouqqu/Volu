# Volu

Классический индикатор громкости в стиле macOS для Windows.

Заменяет стандартный системный ползунок на аккуратный всплывающий оверлей с мягким звуковым щелчком при изменении громкости.

---

### Главное

- **Дизайн macOS** — лаконичная карточка по центру экрана с 16 делениями и динамиком.
- **Приятный щелчок** — уютный звуковой отклик при изменении громкости (можно выбрать звук или выключить).
- **Без лишнего** — полностью скрывает стандартный системный ползунок Windows.
- **Всё под рукой** — настройки звука и автозапуск доступны по правому клику в трее.
